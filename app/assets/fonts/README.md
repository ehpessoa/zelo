# Fontes do HUD

Coloque aqui `RobotoMono-Regular.ttf` e `RobotoMono-Bold.ttf` (Google Fonts,
licença Apache 2.0) usadas pelo `HUDOverlay.tsx` via `useFont` do Skia.
Qualquer fonte monoespaçada TTF funciona — apenas ajuste os nomes de
arquivo no `require(...)` dentro de HUDOverlay.tsx se usar outra fonte.
